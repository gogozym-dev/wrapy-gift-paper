# Bundled fonts

The application self-hosts Latin webfont subsets so Canvas previews and exported PNG files use the same typeface.

- Fredoka 600: SIL Open Font License 1.1 (`fredoka/OFL.txt`)
- DynaPuff 600: SIL Open Font License 1.1 (`dynapuff/OFL.txt`)
- Sour Gummy 600: SIL Open Font License 1.1 (`sour-gummy/OFL.txt`)
- Baloo 2 600: SIL Open Font License 1.1 (`baloo-2/OFL.txt`)

The font files were obtained from Google Fonts. The license text for each family is retained beside its font file.
